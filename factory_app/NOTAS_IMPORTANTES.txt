PORTA DA APLICAÇÃO:
-------------------
A aplicação está configurada para usar a porta 8080 (padrão).

As portas 5000 e 7082 estão evitadas conforme solicitado.

Para alterar a porta, edite o arquivo .env:
    APP_PORT=8080  (altere para a porta desejada)


EXECUÇÃO DA APLICAÇÃO:
---------------------
Para executar tudo de uma vez:

    Opção 1 (Windows): Duplo clique em start.bat
    Opção 2 (Manual): python run.py
    Opção 3 (VS Code): Pressione F5


PRIMEIRA EXECUÇÃO:
-----------------
1. Execute: install.bat (Windows) ou siga README.md
2. Configure .env com credenciais SQL Server
3. Crie base de dados: CREATE DATABASE factory_db;
4. Execute: python init_database.py
5. Execute: python run.py
6. Acesse: http://localhost:8080


UTILIZADORES MÚLTIPLOS:
----------------------
A aplicação suporta 10+ utilizadores simultâneos.
Cada utilizador deve fazer login com suas próprias credenciais.

MÓDULOS DISPONÍVEIS:
-------------------
✓ Dashboard - Visão geral
✓ Ordens de Trabalho - Gestão de ordens
✓ Produção - Registo de produção (início/pausa/fim)
✓ Inventário - Gestão de chapas/maciços com QR codes
✓ Não-Conformidades - Registo de problemas


FUNCIONALIDADES PRINCIPAIS:
--------------------------
✓ Autenticação com 3 níveis de acesso
✓ Registo de tempo (início/fim/pausa/setup)
✓ Quantidade entrada/saída
✓ Múltiplos operadores (até 2 por produção)
✓ QR codes para inventário (geração e leitura)
✓ Relatórios e exportação
✓ Interface responsiva (touch + mouse)


INTEGRAÇÃO SQL SERVER:
---------------------
