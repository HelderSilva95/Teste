Como usar
  1. Configure as credenciais do SQL Server externo no arquivo .env
  2. Reinicie a aplicação para carregar as novas configurações
  3. Teste a conexão usando o botão "Testar Conexão"
  4. Selecione o tipo de dados que deseja importar
  5. Configure os parâmetros (se necessário) e clique em "Importar"

Nota: As queries SQL utilizadas para importação podem ser personalizadas no arquivo utils/sql_import.py. Consulte a documentação técnica para mais detalhes.
